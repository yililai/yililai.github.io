Fully Convolutional Networks for Semantic Segmentation

从 Image Classification 到 Dense Prediction
Yi Li · 2026-09-21
FCN（Fully Convolutional Network）最重要的意义， 并不在于今天它仍然具有多高的 segmentation performance， 而在于它第一次系统地将用于 Image Classification 的 CNN 转化为能够进行 pixel-level Dense Prediction 的网络。 它建立了现代 Semantic Segmentation 的基本范式： 从“整张图像是什么”，走向“图像中的每一个 pixel 是什么”。

Paper： Fully Convolutional Networks for Semantic Segmentation

Authors： Jonathan Long, Evan Shelhamer, Trevor Darrell

Conference： CVPR 2015

Task： Semantic Segmentation

核心关键词： Fully Convolutional Network · Dense Prediction · Upsampling · Skip Connection

1. 为什么需要 FCN：从 Classification 到 Dense Prediction

深度 CNN 最早取得巨大成功的任务主要是 Image Classification。 对于 classification，一张图片经过 convolution、pooling 和 Fully Connected Layer 后，最终只需要输出一个类别：

Image   →   CNN   →   Class

例如输入一张图片，模型只需要判断它属于 cat、dog 或其他类别。 在这个任务中，我们关心的是：

What is in the image?

但 Semantic Segmentation 的目标完全不同。 它不仅需要知道图像中包含哪些类别， 还需要判断图像中 每一个 pixel 属于什么 category。

Image   →   H × W × C

因此 segmentation 属于典型的 Dense Prediction： 网络不再只输出一个 image-level label， 而需要生成具有 spatial structure 的 prediction map。

这也暴露出了传统 classification network 的问题。 CNN 前面的 convolution layer 仍然保留二维 spatial structure， 但在进入 Fully Connected Layer 后， feature map 会被转换为固定长度的 feature vector。

对于 classification 来说这没有问题， 因为最终只需要知道“是什么”。 但对于 segmentation 来说， 我们还必须知道目标 “在哪里”。

因此 FCN 所面对的核心问题可以概括为：

如何把一个只能进行 image-level classification 的 CNN， 转换成可以对整张图像进行 pixel-level prediction 的网络？

2. FCN 的核心：把 Classification Network 改造成 Fully Convolutional Network

FCN 最关键的改变其实非常直接：

Fully Connected Layer   →   Convolution Layer

Fully Connected Layer 看起来和 convolution 完全不同， 但如果从 tensor operation 的角度理解， Fully Connected Layer 实际上可以等价地写成 convolution。

假设某一层 feature map 的尺寸为：

7 × 7 × 512

如果后面连接一个 4096-dimensional Fully Connected Layer， 那么它实际上可以等价地转换为一个 kernel size 为 7 × 7 的 convolution。

这样做以后，网络不再必须把 feature map 压缩成一个 image-level feature vector， 而能够继续保持 spatial structure。

网络因此从：

Image   →   Feature   →   Class

转换为：

Image   →   Feature Map   →   Spatial Prediction

这也是 Fully Convolutional Network 这一名称的来源。

更重要的是， 网络经过 fully convolutional 化之后， 理论上可以接受不同尺寸的输入， 并输出与输入 spatial size 对应的 prediction map。

这一步实际上完成了 segmentation 最重要的范式转变：

CNN 不再只学习一个 image-level representation， 而开始学习可以用于 pixel-level prediction 的 spatial representation。

3. 从 Coarse Prediction 到 Precise Segmentation：Upsampling 与 Skip Connection

把 Fully Connected Layer 改成 convolution 以后， segmentation 仍然没有真正完成。

原因在于传统 CNN 中存在大量 pooling 和 stride operation， feature map 的 resolution 会不断下降。

512 × 512   →   256 × 256   →   128 × 128   →   64 × 64   →   ...

深层 feature 虽然具有更强的 semantic information， 但 spatial resolution 已经非常低。 因此 FCN 需要通过 Upsampling 将 coarse prediction 恢复到原始图像大小。

论文中使用了可学习的 upsampling operation。 早期文献经常称之为 Deconvolution， 现在更常见的名称是 Transposed Convolution。

于是最基本的 segmentation pipeline 形成了：

Image
↓
CNN Feature Extraction
↓
Low-resolution Prediction
↓
Upsampling
↓
Segmentation Map

但如果只是把最后一层低分辨率 feature 直接放大， segmentation boundary 往往非常粗糙。

这里出现了 segmentation 中一个非常重要， 并且直到今天仍然存在的问题：

Deep Feature： semantic information 强，但 spatial resolution 低。

Shallow Feature： spatial detail 丰富，但 semantic information 相对较弱。

换句话说， 网络越往深层越知道 “这是什么”， 但越来越难知道 “精确在哪里”。

为了同时获得 semantic information 和 spatial detail， FCN 开始融合不同层级的 feature， 这就是后面 segmentation 网络中非常经典的 Skip Connection 思想。

论文中的 FCN-32s、FCN-16s 和 FCN-8s 可以理解为这一思想不断增强的三个版本。

Model 主要特点 Spatial Detail
FCN-32s 主要使用最深层 feature，再进行大倍率 upsampling 较粗
FCN-16s 进一步融合 intermediate feature 更精细
FCN-8s 进一步加入更高 resolution 的 shallow feature 最好

从今天来看， Skip Connection 已经成为很常见的设计。 但在当时， 它非常清楚地揭示了 segmentation 中的一个基本矛盾：

Segmentation 不仅需要 semantic understanding， 还需要 precise localization。

这一思想后来在 U-Net 中被进一步强化， 并逐渐成为 Encoder–Decoder segmentation architecture 的核心设计之一。

4. FCN 真正解决了什么，又没有解决什么？

如果只从今天的 performance 来看， FCN 已经是一个非常简单的 segmentation model。 但评价一篇经典论文， 更重要的是看它是否改变了一个领域解决问题的方式。

FCN 最大的贡献并不是某一个具体 module， 而是建立了现代 Semantic Segmentation 最基本的范式：

Image   →   Feature Map   →   Dense Prediction

在这个框架下， segmentation 不再需要把一张图切成大量 patches 分别进行 classification， 而能够通过一次 forward pass， 直接得到整幅图像的 pixel-level prediction。

但是 FCN 同样暴露出了两个非常明显的问题。

第一个问题是 small object information 容易在 downsampling 中丢失。

对于一个尺寸很大的 object， 即使经过多次 downsampling， 它仍然能够在 deep feature map 中占据明显区域。 但对于尺寸只有几个 pixels 的 small object：

4 × 4   →   2 × 2   →   1 × 1   →   ?

经过连续 pooling 或 stride operation 后， 目标可能只剩下极少的响应， 甚至直接消失。

后面的 upsampling 能够放大 feature map， 却不能真正恢复已经完全丢失的信息。

第二个问题更加本质：

FCN 预测的是 Pixel Category， 而不是 Object Identity。

FCN 学习的是：

Pixeli   →   Classi

例如对于细胞核， 网络可以判断某个 pixel 属于 nucleus， 但它并不知道：

Pixel A → Nucleus 1

Pixel B → Nucleus 2

当两个同类别 object 紧密接触时， semantic segmentation 很容易把它们预测成一个连续区域。

因此 FCN 能回答：

“这个 pixel 是什么？”

但它没有回答：

“这个 pixel 属于哪一个 object？”

这就是从 Semantic Segmentation 继续走向 Instance Segmentation 时必须解决的问题。

5. 从 FCN 看 Dense Object Segmentation

对我目前关注的 Dense Object Segmentation 来说， FCN 最值得思考的地方并不是它具体使用了什么 backbone， 而是它暴露出了 segmentation 中两个不同层次的问题：

① Spatial Resolution
Dense small objects 对 fine-grained spatial information 非常敏感。 多次 downsampling 很容易使 small object feature 被削弱甚至消失。
② Object Representation
即使已经非常准确地预测 foreground pixels， 也并不意味着模型知道这些 pixels 分别属于哪一个 object。

第一个问题关注的是：

如何尽可能保存 small object 的 spatial information？

这条路线后来会自然发展到 multi-scale feature、Encoder–Decoder、 Skip Connection、FPN 等设计。

第二个问题则进一步指向：

如何形成真正具有 object identity 的 representation？

这正是后续 Mask R-CNN、StarDist、HoVer-Net、DETR、MaskFormer 等工作逐渐开始回答的问题。

从这个角度来看， FCN 可以被看作整个现代 segmentation 演化链条的起点：

Pixel Classification
↓
Better Spatial Representation
↓
Instance Separation
↓
Object-level Representation

FCN 首先完成了最关键的一步： 让 CNN 从 image-level classification 进入了 pixel-level dense prediction。

但对于 dense object segmentation 来说， 这只是问题的开始。

My Takeaway
FCN 解决了“每一个 pixel 是什么”的问题， 但没有解决“这些 pixels 如何组成不同 objects”的问题。

对于 dense small object segmentation， 后者可能比单纯提高 pixel classification accuracy 更值得关注。

下一篇将继续阅读 U-Net。 如果说 FCN 建立了 Dense Prediction 的基本框架， 那么 U-Net 所进一步回答的问题就是：

在连续 downsampling 已经损失大量 spatial detail 的情况下， 如何更有效地恢复精细的 segmentation result？
