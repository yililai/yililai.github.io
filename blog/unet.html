U-Net: Convolutional Networks for Biomedical Image Segmentation

从 FCN 到 Encoder–Decoder：如何结合语义理解与精细定位？
Yi Li · 2026-10-24
U-Net 的核心思想，是通过对称的 Encoder–Decoder 结构和 Skip Connection，将深层特征的语义信息与浅层特征的空间细节结合起来。 此外，它还通过强数据增强和针对细胞边界设计的加权损失， 提高了模型在有限标注数据下的训练效果。 对医学图像分割而言，U-Net 不只是一个经典网络结构， 也是理解多尺度特征融合的重要起点。

Paper：U-Net: Convolutional Networks for Biomedical Image Segmentation

Authors：Olaf Ronneberger, Philipp Fischer, Thomas Brox

Conference：MICCAI 2015

Task：Biomedical Image Segmentation

Keywords：Encoder–Decoder · Skip Connection · Data Augmentation · Weighted Loss

Paper： arXiv:1505.04597

Official Project： U-Net Project Page

1. 为什么需要 U-Net：医学图像分割的两个难题

在上一篇 FCN 中，我们看到 CNN 可以从 Image Classification 转变为 Dense Prediction，但这并不意味着分割问题已经得到解决。 连续的 Downsampling 能够扩大感受野、提取更高层次的语义信息， 同时也会降低特征图的空间分辨率，使目标边界和细小结构难以精确恢复。

对医学图像而言，这个问题尤其突出。一方面，细胞、神经结构等目标 可能具有复杂的形态和紧密的空间关系；另一方面，医学图像的像素级标注 通常成本较高，很难像自然图像那样获得大规模标注数据。 因此，模型既要准确理解图像中的结构，又要尽可能有效地利用有限的训练样本。

U-Net 正是围绕这两个问题展开。它采用一个用于提取上下文信息的 Contracting Path，以及一个用于恢复空间分辨率的 Expansive Path， 并通过 Skip Connection 将两侧对应层级的特征连接起来。 作者还利用强数据增强，使网络能够从相对较少的训练图像中学习。

U-Net 的核心问题： 如何在提取高层语义信息的同时，保留足够精细的空间信息， 并在有限标注数据下训练出可靠的分割模型？

2. U-Net 的核心结构：Encoder–Decoder 与 Skip Connection

U-Net 的结构呈 U 形，可以分为左右两条路径。 左侧的 Encoder 逐步降低特征图分辨率、增加通道数， 以提取更丰富的上下文信息；右侧的 Decoder 则逐步上采样， 恢复空间分辨率并生成最终的 segmentation map。

在原始 U-Net 中，Encoder 的每个阶段通常包含两次 3×3 Convolution 和 ReLU，随后通过 2×2 Max Pooling 将空间尺寸缩小一半。随着网络加深，特征通道数逐渐增加。 Decoder 使用 Up-convolution 提高分辨率， 再将对应 Encoder 阶段的高分辨率特征复制并拼接， 最后通过卷积进一步融合这些信息。

Encoder： Spatial Resolution ↓，Semantic Context ↑

Decoder： Spatial Resolution ↑，Prediction Detail ↑

Skip Connection： Encoder Feature ⊕ Decoder Feature

这里最值得理解的是 Skip Connection。 如果只依靠最深层特征进行上采样，模型虽然拥有较强的语义理解能力， 但浅层的边缘、纹理和局部结构信息可能已经被削弱。 Skip Connection 将这些高分辨率特征直接传递给 Decoder， 让模型在恢复空间分辨率时仍然可以利用局部细节。

需要注意，原始 U-Net 的 Skip Connection 使用的是 Feature Concatenation，而不是简单的逐元素相加。 拼接后，Decoder 可以通过后续卷积学习如何组合浅层与深层信息。 这使得网络不仅能恢复空间尺寸，还能重新融合不同层级的特征。

原始论文使用不带 Padding 的 3×3 Convolution， 因此每次卷积都会缩小特征图尺寸，拼接前需要裁剪对应的 Encoder Feature。 论文中的示例输入尺寸为 572×572，输出尺寸为 388×388。 现代实现中常使用 Padding 来保持尺寸，因此不一定出现这一差异。

从方法设计来看，U-Net 的重点不是简单地“把图像放大回来”， 而是让 Decoder 在恢复分辨率的过程中， 重新获得 Encoder 早期保留下来的空间信息。

3. 为什么 U-Net 有效：不仅是网络结构

U-Net 的效果来自几个相互配合的设计。 首先，Encoder 提供较大感受野下的上下文信息， Decoder 逐步恢复空间分辨率， Skip Connection 则补充高分辨率特征。 这三者共同缓解了语义理解与精细定位之间的矛盾。

其次，作者非常重视 Data Augmentation。 医学图像中往往只有有限数量的标注样本， 因此单纯依赖已有图像训练容易过拟合。 除常见的几何变换外，原论文特别采用了 Elastic Deformation（弹性形变）， 通过对图像进行局部、平滑的形变， 生成形态不同但仍具有合理结构的训练样本。 对细胞等具有较大形态变化的生物医学目标而言， 这种增强方式尤其有价值。

此外，原始 U-Net 还设计了针对像素类别和边界的 Weighted Loss。 对于彼此紧邻、容易粘连的细胞， 作者会提高相邻实例之间分隔区域的像素权重， 让模型更加关注这些难以区分的位置。

w(x) = wc(x) + w0 exp [−(d1(x) + d2(x))² / (2σ²)]

这里的 wc(x) 用于平衡不同类别的像素权重； d1(x) 和 d2(x) 分别表示像素到最近和次近细胞边界的距离； w0 与 σ 控制边界权重的强度和作用范围。 当像素位于两个细胞之间的狭窄区域时， 两个距离之和通常较小，指数项相应增大， 从而使训练更加关注这些容易发生实例粘连的位置。

因此，U-Net 的成功不能简单归结为 U 形结构。 更准确地说，它将多尺度特征融合、针对有限样本的数据增强， 以及面向分割难点的损失设计结合起来。 原论文在神经结构分割和细胞相关任务上的实验， 也展示了这种组合的有效性。

4. U-Net 的贡献与局限：分割准确不等于实例区分

U-Net 的重要贡献，是形成了一种简洁而有效的 Encoder–Decoder 分割框架。 它使高层语义特征和浅层空间细节能够在多个分辨率上融合， 同时通过强数据增强改善有限标注数据下的训练效果。 这套思路后来被大量医学图像分割方法采用和扩展。

但从密集小目标分割的角度来看，U-Net 仍有两个值得区分的问题。 第一个是小目标的特征保留问题。 Skip Connection 能够传递浅层的高分辨率特征， 却不能保证所有微小目标都能在反复 Downsampling 后被充分保留。 如果目标在深层特征中已经变得不明显， 仅靠 Decoder 上采样并不能凭空恢复丢失的信息。

第二个问题更为关键：Semantic Segmentation 不等于 Instance Segmentation。 标准 U-Net 可以输出每个像素属于前景还是背景， 但它本身并不必然为每个细胞分配独立的实例 ID。 即使前景区域的 Dice 很高，相邻的两个细胞仍可能被预测为一个连通区域。

原始 U-Net 的边界加权损失确实能够帮助区分紧邻目标， 但这不意味着普通二分类输出天然就具备完整的实例表示能力。 对于密集细胞核任务，通常还需要实例级监督、 边界或距离表示、后处理，或者专门的实例分割解码机制， 才能更可靠地处理目标粘连和实例身份区分。

问题 U-Net 能提供什么 仍然存在的限制
空间定位 通过 Skip Connection 融合高分辨率特征 无法保证所有细小结构都被保留
有限标注数据 通过强 Data Augmentation 提高样本利用效率 无法完全消除数据分布差异带来的问题
相邻目标分离 边界加权损失可以强化难分区域的学习 标准像素分类输出不直接编码实例身份

5. 从 U-Net 看 Dense Object Segmentation

对我关注的 Dense Object Segmentation 而言， U-Net 最重要的启发是： 空间细节的恢复与实例身份的区分，是两个相关但不同的问题。 Skip Connection 解决的是不同层级特征如何融合， 让模型在判断目标类别时仍能利用细粒度的空间信息； 但它并没有直接回答哪些像素属于同一个实例。

例如在密集细胞核图像中， 模型可能已经准确预测了整片核区域， 却仍然无法可靠地分开相互接触的细胞。 这时继续改善边界定位可能有帮助， 但真正解决问题还需要让模型学习实例之间的区别。 因此，研究中必须区分 Pixel-level Accuracy、 Boundary Localization 和 Instance Separation， 而不能只依赖单一的像素级指标判断模型是否有效。

My Takeaway
U-Net 让我看到，分割网络的设计不只是不断堆叠更强的特征提取模块， 还需要明确不同层级的特征分别提供什么信息， 以及这些信息如何共同支持最终的预测。

对密集小目标来说，保持高分辨率特征是重要的一步， 但更深层的问题是： 模型如何从像素特征中建立可靠的 Object Representation， 并在目标紧密接触时保持实例身份的可区分性？

如果说 FCN 建立了端到端 Dense Prediction 的基本范式， 那么 U-Net 则进一步探索了如何结合语义信息与空间定位。 下一篇 Mask R-CNN 将从另一个角度继续推进这个问题： 不再只预测像素类别，而是尝试显式地检测对象， 并为每个对象生成独立的 Mask。
